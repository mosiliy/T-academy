# Vision

## Цель проекта

Создать приложение для удобного управления домашними запасами.

## Проблема

Пользователи забывают:
- какие продукты есть дома
- что нужно купить
- сроки годности продуктов

## Решение

Система позволяет централизованно хранить информацию о запасах.
