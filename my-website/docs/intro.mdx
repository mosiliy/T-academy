# Home Supplies App

Документация приложения для управления домашними запасами.

## Назначение системы

Система предназначена для:
- хранения списка домашних запасов
- отслеживания остатков продуктов
- формирования списка покупок
- уведомления о заканчивающихся товарах

## Основные возможности
- добавление и удаление продуктов
- просмотр запасов
- поиск продуктов
- создание списка покупок

## Технологии
- Frontend
- Backend REST API
- SQLite / PostgreSQL
- GitHub Actions
- Docusaurus
